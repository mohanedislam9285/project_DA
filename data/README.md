# Local data files

The raw and processed tables are not cleared for unrestricted redistribution. Download the upstream data from the Kaggle URL in `manifest.yaml`, review its current license/attribution terms, then verify each listed file against the manifest SHA-256 values. The compiled dataset's Kaggle license is recorded as “Other (specified in description)”; do not assume the upstream component licenses automatically resolve rights for the compiled bundle.

`data/raw/extracted/combined_gee_pm25.csv` is the active prepared combined input. The package does not contain an auditable record proving the precise upstream joining algorithm. `data/processed/cleaned_daily.csv` is regenerated by the `audit` command using the configured schema and cleaning rules.

For professor reproduction, keep the locally obtained source files in their manifest paths and run the documented audit command. Do not run any future-test evaluation command.
