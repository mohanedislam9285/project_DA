analysis stages align with the M1 Data Science syllabus.

2. CNN-LSTM: internal model layers
These are Keras components inside TensorFlow. They are layers or model components, not separate Python
packages.
Order
Keras component
Role in the model
1
Input
Receives historical measurements as a time-window sequence.
2
Embedding (optional)
Represents station identity when station information is used.
3
Conv1D
Extracts local patterns across adjacent time steps.
4
LayerNormalization
Normalizes intermediate activations.
5
Activation (ReLU)
Adds non-linearity.
6
Dropout
Helps reduce overfitting during training.
7
MaxPooling1D
Reduces the sequence length.
8
LSTM
Learns temporal relationships in the sequence.
9
Dense
Combines learned features for prediction.
10
Output Dense(1)
Returns the predicted PM2.5 value (single-target setup).
3. Recommended Python packages to install
Package
Priority / use
Pandas, NumPy
Essential: data handling and numerical arrays.
Matplotlib, Seaborn
Essential: exploratory and result visualizations.
Scikit-learn
Essential: preprocessing, clustering and evaluation metrics.
SciPy, Statsmodels
Essential for syllabus methods: statistical tests, regression and time series.
TensorFlow

For PCA, CA, MCA and MFA.
Plotly
Optional: interactive charts.
kmedoids
Optional: K-medoids clustering (Chapter 4).
Installation command
pip install pandas numpy requests openmeteo-requests matplotlib seaborn scikit-learn scipy
statsmodels tensorflow prince plotly kmedoids
Practical note: You do not need every listed package inside the CNN-LSTM network. TensorFlow/Keras builds and trains the
network; Pandas and NumPy prepare its input; Scikit-learn and plotting libraries help evaluate and present the results.
